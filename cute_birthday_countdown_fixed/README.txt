# Birthday Countdown ♡

A simple, cute 3-day birthday countdown and birthday wishing website. The countdown shows the remaining days, hours, minutes, and seconds live, with '3 days more', '2 days more', and '1 day more' messaging.

## Files
- index.html
- style.css
- script.js

## Run
Keep all three files in the same folder and double-click `index.html`.

The countdown is set for:
September 14, 2026 → September 17, 2026.

It uses your computer/browser's local time.
